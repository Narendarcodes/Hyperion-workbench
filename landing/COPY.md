## Positioning
**Heading:** Sensitive work should not force a choice between control and progress.

**Description:** HYPERION turns controlled sources into reviewable analysis and usable deliverables without handing consequential industrial decisions to an AI system.

**Two statements:**
- Cloud AI creates a confidentiality barrier.
- Manual workflows create a productivity barrier.

## Operating model
**Heading:** Evidence stays in the loop.

**Description:** A visible path from source material to human decision — each stage is traceable, bounded, and reviewable.

1. **Task** — Create a controlled task and attach local sources.
2. **Evidence** — Parse inputs and retrieve authorized, version-aware knowledge.
3. **Analysis** — Plan and perform multi-step work with approved local models and tools.
4. **Verify** — Group high-risk claims with source evidence and uncertainty.
5. **Decide** — Keep approval, correction, rejection, and change requests human-controlled.
6. **Deliver** — Generate a reviewable artifact with trace metadata.

## Capabilities
**Heading:** Built for difficult industrial knowledge work.

- **Multimodal intake** — Inspect scanned PDFs, photographs, handwriting, tables, and native documents locally.
- **Evidence-grounded knowledge** — Retrieve controlled sources with revision, authority, and page or section context.
- **Local model routing** — Choose an approved local model by task type, modality, and available compute.
- **Bounded tool gateway** — Use permitted OCR, calculation, document, spreadsheet, and file tools with audit records.
- **Sandboxed execution** — Run code and calculations with resource limits and no unrestricted network access.
- **Verified deliverables** — Produce DOCX, XLSX, and working code from verified task state.

## Workflow
**Heading:** One task. A complete evidence trail.

1. Capture — Source PDF, image, or document enters a controlled location.
2. Start — Engineer creates a task and links sources.
3. Understand — OCR, vision, and parsing identify content and subtasks.
4. Ground — Local knowledge retrieval attaches source evidence.
5. Analyze — The agent produces findings and flags uncertainty.
6. Verify — The engineer confirms, corrects, or rejects high-risk claims.
7. Deliver — A verified DOCX, XLSX, or code artifact is generated.
8. Review — A manager reviews findings, evidence, and outstanding flags.
9. Close — The final decision and trace are archived.

## Roles
**Heading:** Control is distributed deliberately.

- **Department manager** — Concise decision review with evidence and claim-level changes.
- **Security and infrastructure** — Read-only status for policy, model, corpus, and sovereignty visibility.
