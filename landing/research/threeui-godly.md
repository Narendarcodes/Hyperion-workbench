# ThreeUI + Godly — Reference Verdicts

**Observed:** 2026-09-09 by static extraction. A later browser-probe session was stale after model handoff; static extraction remains the recorded evidence.

## ThreeUI
- Catalog evidence: Three.js components/templates including Structure Flow, Predictive Arc, Data Pixel Arc, Signal Particles, Override Grid, Logic Core, Data Field, Topology Field, and interactive shader/button examples.
- **Steal:** the idea of a discrete data/infrastructure field, bounded to a product-proof surface.
- **Skip:** direct ThreeUI component installation. The landing already uses a real source-derived Originkit Hex Comb hero. Adding another WebGL subsystem increases GPU/interaction cost without a second product story.
- **Verdict:** Use the catalog as motion vocabulary only: controlled geometry, no neon, one contained WebGL field.

## Godly
- Catalog evidence: curated gallery of web/app/UI work; useful for layout and composition references, not reusable source.
- **Steal:** large unbroken type, strong negative space, a visible product object instead of generic feature-card stacks, and one strong signature interaction per page.
- **Skip:** visual novelty for its own sake. Do not turn industrial controls into a creative portfolio or copy generic startup composition.
- **Verdict:** HYPERION carries one visual focal point (hero hex field) and one narrative focal point (pinned evidence path); the rest is quiet and highly legible.
