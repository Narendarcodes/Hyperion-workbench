Agent = Model + Harness

The model is the soul of an agent.
A harness lets it understand its environment, use tools, and keep working in real-world settings.

Capabilities as plugins

Swap any capability
without touching the source

Plugins provide every agent capability and work together through Cordis services and events. Select, swap, or extend anything in configuration.

Models

Every model interface is a plugin — pick providers per task, swap without code changes.

Tools & skills

Shell, filesystem, web, and skill catalog — each registered through the same service boundary.

Sessions & trace

Every run lands in an append-only log — system prompts, reasoning, tool calls, subagent scheduling, context injections.

Sandboxes & storage

E2B sandboxes and durable session data — isolated execution, persistent results.

Loops & scheduling

Loop hygiene, tool timeouts, and scheduled jobs keep long-running agents on rails.

The UI

Even the interface is a plugin — recompose the web app, TUI, or headless modes in config.

Runtime modes

One harness, four ways to run

Standard

Full coding agent

File editing, shell, file and web search, skills, planning, goals, subagents, and workflows — the complete toolset.

dsh --profile standard

Code

Tools as code

All Standard capabilities, with tools exposed through the Code Mode SDK so the model combines multi-step operations in one TypeScript program.

dsh --profile code

Minimal

Two-tool benchmark

Persistent bash and str_replace_editor only — for benchmarking models in a minimal environment.

dsh --profile minimal

Creator

Preset authoring

Inspect the live runtime, test Cordis plugins in memory, and combine them into new modes — with preset-authoring guidance built in.

dsh --profile creator
