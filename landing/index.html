Agent = Model + Harness

The model is the soul of an agent — the harness is everything else.
DeepSeek Harness lets a model understand its environment, use tools, and keep working in real-world settings. We compose ours for the hackathon floor.

Why we built on it

The harness moves the score

DeepSeek runs its published agent benchmarks through Harness minimal mode — fixed sampling, maximal reasoning effort, two tools — so scores are reproducible instead of tuned per benchmark. The numbers below are DeepSeek's own, run on the same engine our hackathon build extends.

BenchmarkV4-Pro GAV4-Flash
Terminal-Bench 2.187.982.7
Cybergym83.376.7
Toolathlon (verified)74.170.3
DSBench-FullStack71.168.7
DSBench-Hard67.259.6
DeepSWE62.754.4
NL2Repo61.554.2

Same weights, different harness: an independent rerun of V4-Flash on a third-party harness swung Terminal-Bench by twenty tasks. That swing is the whole reason a hackathon on harness architecture is worth running.

Interop

Plays with NVIDIA OpenShell

Our sandbox plugins follow the same bet NVIDIA made with OpenShell — out-of-process policy enforcement. OpenShell (Apache 2.0) wraps any coding agent in isolated sandboxes with deny-by-default permissions, live policy updates, and a full audit trail. A single command moves an agent inside: openshell sandbox create --from openclaw.

Sandboxed sessions, metered resources, every allow/deny decision logged — the direction we point our own sandbox plugins in.

openshell — gateway policy

Capabilities as plugins

Swap any capability
without touching the source

Plugins provide every agent capability and work together through Cordis services and events. Select, swap, or extend anything in configuration.

Models

Every model interface is a plugin — pick providers per task, swap without code changes.

Tools & skills

Shell, filesystem, web, and skill catalog — each registered through the same service boundary.

Sessions & trace

Every run lands in an append-only log — system prompts, reasoning, tool calls, subagent scheduling, context injections.

Sandboxes & storage

E2B sandboxes and durable session data — isolated execution, persistent results.

Loops & scheduling

Loop hygiene, tool timeouts, and scheduled jobs keep long-running agents on rails.

The UI

Even the interface is a plugin — recompose the web app, TUI, or headless modes in config.

Runtime modes

One harness, four ways to run

Standard

Full coding agent

File editing, shell, file and web search, skills, planning, goals, subagents, and workflows — the complete toolset.

dsh --profile standard

Code

Tools as code

All Standard capabilities, with tools exposed through the Code Mode SDK so the model combines multi-step operations in one TypeScript program.

dsh --profile code

Minimal

Two-tool benchmark

Persistent bash and str_replace_editor only — for benchmarking models in a minimal environment.

dsh --profile minimal

Creator

Preset authoring

Inspect the live runtime, test Cordis plugins in memory, and combine them into new modes — with preset-authoring guidance built in.

dsh --profile creator
